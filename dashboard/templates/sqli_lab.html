Architectural Code Difference

Insecure Implementation (Vulnerable)

Unsanitized string interpolation places raw input into SQL interpreter:

# VULNERABLE: Direct string formatting
raw_query = f"SELECT * FROM users WHERE username = '{username}' AND password_hash = '{pw_hash}'"
cursor.execute(raw_query)

Hardened Implementation (Remediated)

Strict regex validation + Parameterized prepared statements:

# SECURE: Regex check + Parameter binding
if not re.match(r"^[a-zA-Z0-9_\-]{3,30}$", username):
    return {"status": "validation_error"}
query = "SELECT id, username, email FROM users WHERE username = ? AND password_hash = ?"
cursor.execute(query, (username, pw_hash))
